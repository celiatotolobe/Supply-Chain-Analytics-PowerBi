# Supply Chain Analytics Dashboard | Power BI

# Project Overview

This project analyzes supply chain performance using Power BI. The goal was to identify operational inefficiencies, supplier trends, inventory risks, and delivery performance.

# Tools Used
- Power BI
- Excel
- Data Cleaning
- Data Visualization
- Supply Chain Analytics
- Lean Six Sigma Principles

# Key Analysis Areas
Supplier Performance:
- Supplier reliability
- Delivery times
- Defect rates
- cost impact

Inventory Analysis
- Inventory levels
- stock risks
- Product demand trends

# Key Insights
- Identified suppliers with higher defect rates
- Compared delivery performance across regions
- Analyzed inventory efficiency
- Highlighted areas for process improvement

# Future Improvements
- Add predictive analytics for demand forecasting
- Implement supplier risk scoring
- Integrate SQL database connection
